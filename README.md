# Misión Prompt: Entrena a la IA

Juego web educativo creado como apoyo para una capacitación docente sobre el uso práctico, crítico y responsable de la Inteligencia Artificial generativa.

## Objetivo

Ayudar a docentes de educación básica y media a identificar y construir mejores prompts educativos mediante diez situaciones de selección múltiple con retroalimentación inmediata.

La actividad trabaja la estructura:

**R + C + T + F = Rol + Contexto + Tarea + Formato**

También aborda verificación de información, privacidad y mejora iterativa de instrucciones.

## Funcionalidades

- Diez misiones educativas.
- Opciones y primeras nueve preguntas en orden aleatorio.
- Reto integrador al final.
- Retroalimentación inmediata.
- Puntaje, porcentaje y barra de progreso.
- Tres niveles de desempeño.
- Reinicio completo sin recargar la página.
- Diseño adaptable y navegación por teclado.
- Sin registro ni almacenamiento de datos personales.

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla

No utiliza backend, base de datos, frameworks ni dependencias que requieran instalación.

## Cómo ejecutarlo

Descarga o clona el repositorio y abre `index.html` en cualquier navegador moderno. También puedes servir la carpeta con un servidor web local.

## Publicación con GitHub Pages

1. Abre **Settings** en el repositorio.
2. En el menú lateral, entra a **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda los cambios.
6. Espera a que GitHub muestre la URL pública.

La aplicación funciona completamente como sitio estático y utiliza rutas relativas compatibles con GitHub Pages.

## Uso educativo responsable

La IA puede apoyar la creación de contenidos y actividades, pero el criterio pedagógico, la verificación de información y las decisiones educativas siguen siendo responsabilidad del docente.
